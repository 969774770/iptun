============================================================
 iptun 公网IP落地客户端（Windows）使用说明
============================================================

【文件】
  iptun-gui.exe     ★ 图形设置程序（普通用户用这个）
  iptun-client.exe  隧道客户端内核（由 GUI 自动管理，无需手动运行）
  wintun.dll        官方虚拟网卡驱动（必须与程序同目录）
  使用说明.txt       本文件

============================================================
一、最简单用法：图形界面（推荐）
============================================================
  1. 右键 iptun-gui.exe → 以【管理员身份】运行

  2. 在界面只需要填 3 项：
       服务器地址  例如 1.2.3.4:7000
       Token       服务器 Web 控制台发放的授权码（也是隧道加密密钥）
       实例名称    默认 IPTun；同一台电脑挂多个客户端时分别取
                   IPTUNA、IPTUNB 等不同名字

  3. 点【保存并启动】，看到“运行中 · 已连接”即可。

  说明：
   · Token 既是登录凭证又是隧道加密根密钥（AES-256-GCM），
     每个客户端一把独立密钥，无需再单独配置“节点密钥”。
   · 【停止】暂停隧道（配置保留）；【卸载服务】删除系统服务。
   · 服务开机自启、崩溃 5 秒自动重启。

============================================================
二、效果
============================================================
  启动后本机出现一张 wintun 虚拟网卡，服务器把分配给你的
  端口段流量（任意 TCP/UDP）原样送到本机：
    · 本机任何监听 0.0.0.0 的服务无需改造即可被公网访问
    · 服务看到的对端地址是访问者【真实公网 IP】
    · 本机平时上网的出口 IP 完全不变

============================================================
三、命令行用法（高级/无人值守）
============================================================
  安装服务（管理员 CMD）：
    iptun-client.exe -install -server 1.2.3.4:7000 -token 你的Token -adapter IPTun
    sc start IPTunClient_IPTun

  前台调试（关窗即停）：
    iptun-client.exe -server 1.2.3.4:7000 -token 你的Token

  卸载：
    iptun-client.exe -uninstall -adapter IPTun

  云服务器安全组需放行被分配的业务端口和隧道 UDP 端口（默认7000）。
